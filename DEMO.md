# Demonstration walkthrough

1. Register one organiser and one attendee (US1).
2. As organiser, create an event; show its `pending` status on the dashboard (US2, USP admin approval).
3. Manually promote a registered account to admin using the documented SQL, log in, then approve the event (US10).
4. Show that the event now appears in the public event list without login (US4).
5. Log in as attendee and book one place; show places remaining and My Bookings (US5, USP supply/demand).
6. Fill the capacity with separate attendee accounts, then join the waiting list; show FIFO queue in attendee list (US6).
7. Cancel a booking and show that the earliest waitlist person is identified, while explaining this MVP does not offer/allocate automatically.
8. As organiser, show the dashboard, Add Places, attendee list, and manual check-in (US8/US9).
9. From the organiser dashboard, open and print the approved event's A4 poster with its QR code and readable short URL (US3, USP low-resource advertising).

Use the limitations in `PROJECT_STATUS.md` honestly during the presentation.
